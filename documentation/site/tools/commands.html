Entry pointOptions
run_taskusage: run_task [-h] [--model MODEL] [--tokenizer TOKENIZER] [--cfg YAML] [--override SECTION.FIELD=VALUE] [--device DEVICE] [--num_devices NUM_DEVICES] [--task TASK] [--present {probs,argmax,full,table}] [--attention IMPLEMENTATION] [--sweep POINTS] [--sweeps] [-i] [--text TEXT] [--input INPUT] [-o OUTPUT] [--column COLUMN] [--label LABEL] [-n LIMIT]
--modelmodel checkpoint; omit to build the model described by the configs, untrained
--tokenizerHF tokenizer id; default: the one the checkpoint was trained with
--cfgconfig file(s), merged left to right; each may hold any section
--overrideoverride applied after the YAMLs, ex. task.test.topk=false; it can address the task selected with --task, even if new
--devicecuda/cpu/mps (default: cuda if available)
--num_devicesdevices for the data loaders
--tasktask entry or task type to drive (default: the first one declared)
--presenthow a prediction is shown: label with its probability (default), the label alone, or everything the task computed
--attentionattention implementation to build the model with, ex. flashinfer (paged KV cache) or sdpa; same as MATFORMER_ATTENTION_NORMAL
--sweeponly these points of the config's sweep: numbers (1-based) or name globs, comma separated. Default: every point of it.
--sweepsprint the sweep the configs declare -- every point, and what it changes -- and run nothing
-i, --interactiveinteractive console
--textrun the task on this text and print the result
--inputannotate this jsonl/csv file
-o, --outputwhere to annotate (default: <input>.annotated.jsonl)
--columncolumn holding the text
--labelcolumn holding the gold label, if any
-n, --limitprocess only the first N rows
trainusage: build.py [-h] [--cfg YAML] [--override OVERRIDE] [--gpu GPU] [--nodes NODES] [--checkpoint CHECKPOINT] [--reset RESET] [--start-from-scratch] [--max-steps MAX_STEPS] [--ckpt-version CKPT_VERSION] [--compile] [--device {auto,cuda,cpu,mps,tpu}] [--no-save-model] [--no-save-plugins] [--sweep POINTS] [--sweeps] [--gpus GPUS] [--probe [KEY=VALUE ...]] [--then-train] [--queue [HOST:PORT]]
--cfgOne or more YAMLs; they merge left to right.
--overrideIn-line overrides (ex. data.batch_size=48), merged left to right.
--gpuNumber of GPU(s)
--nodesNumber of Node(s)
--checkpointCheckpoint to resume from (see --reset)
--resetWhat to reset: lr_scheduler, optimizer, datamodule, steps
--start-from-scratchIgnore the checkpoint's weights, advance the version
--max-stepsTrain one epoch over this many steps
--ckpt-versionResume a specific checkpoint version
--compiletorch.compile the whole model
--deviceAccelerator (default: detect)
--no-save-modelSkip model saving
--no-save-pluginsSkip plugins saving
--sweepOnly these points of the config's sweep: numbers (1-based) or name globs, comma separated. Default: every point.
--sweepsPrint the sweep the configs declare -- every point, and what it changes -- and run nothing
--gpusPin the run to these devices, e.g. '2,3' (CUDA_VISIBLE_DEVICES)
--probeMeasure the largest batch the GPUs fit and how fast it runs (knobs: fill, max_rows, steps, keep_weights); without --then-train nothing is trained
--then-trainAfter probing, train at the batch size the probe found
--queueAsk a server to run this instead: its address, or nothing for a local one
