Logging

MatformerLogger collects the metrics of one optimizer step and sends the row to every backend. Backends are registered in the logger category.

training:
  logger: [jsonl, tqdm]

MatformerLogger

log(key, value, step=None, prog_bar=False) writes to the current row. advance() sends the row to the backends and advances the step. flush() sends the row without advancing. reset() clears the bars, and close() flushes and closes the backends.

A backend with a buffer method is treated as a progress bar. It receives buffer, advance, reset and close. Other backends receive log(row, step) and optionally define_step_metric.

Backends

Variant Output
jsonl run.jsonl, config.json and meta.json under {save_dir}/logs/{run_name}_v{version}/
wandb a Fabric WandbLogger; hyperparameters and one row per step
tqdm a progress bar, disabled on every rank except 0

The JSONL backend has no external dependency. A run folder is computed by run_dir_for(training_configs), the same function used by the memory probe, so memory_probe.json is written next to the run log. A resumed run keeps the original started value from meta.json.

flatten_configs(configs) converts a MatformerConfigs object to section/entry/field keys. It is used by the backends that store hyperparameters.

Scoped logging

logger.scoped(prefix) returns a logger that prefixes each key with prefix/ and uses its own prefix/step. It does not advance the parent step or close the parent backends. sandbox_train uses it for the training runs it starts inside a validation step.

Environment variables

LOG_WANDB, LOG_TQDM and LOG_PROGRESS_BAR_STEPS control the defaults. See Environment variables.

Logged metrics

The wrapper logs train/loss, train/aux_loss, the learning-signal metrics (train/accuracy from post_loss), train/skipped_oom, train/EXCEPTIONS, and lr0, lr1, ... for the schedulers. The trainer adds speed/*: tokens per second, sequences per second, TFLOPs, MFU and step time, measured over log_speed_every_n_steps steps. Tasks log their summary under <task name>/<metric>.
